# Site Gas Hub Tech

Site institucional da Gas Hub Tech (gashub.tech): apresentação do GTRM, módulos da plataforma, perfis, segurança, roadmap e contato.

Página estática, sem build: abra `index.html` no navegador ou publique a pasta em qualquer hospedagem estática (Vercel, Netlify, GitHub Pages).

## Estrutura

```
index.html        página completa (HTML, CSS e JS)
ght-video.mp4     vídeo de apresentação do GTRM
img/              logo oficial, favicon e telas da plataforma recortadas do vídeo
```

## Identidade visual

Segue o Design System "Gas Hub Tech": navy `#0c1951`, teal `#168e8e`, Montserrat (títulos), IBM Plex Sans (texto) e IBM Plex Mono (números), carregadas do Google Fonts. Os tokens ficam no topo do `<style>` em `index.html`.
